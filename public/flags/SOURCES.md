# Country flags

3×2 SVG flags from [country-flag-icons](https://gitlab.com/catamphetamine/country-flag-icons)
1.6.20 (npm `country-flag-icons/3x2`), MIT license, copied unchanged on 2026-10-26.
The license is in `LICENSE.txt`. Only two-letter codes are kept; subdivision flags
(`GB-SCT`, `ES-CT`, …) are omitted because Steam profiles store a country, not a region.

Bundled locally so a flag needs no request per player and works offline. The list of
accepted codes in `src/shared/country.ts` must match the files here (tested).
